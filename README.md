# Sales Analysis by Outlet Size and Location Type

## Project Overview
This project focuses on analyzing sales performance based on different outlet sizes and outlet location types using Python. The analysis helps understand how outlet size and location contribute to overall sales.

## Tools & Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed

### 1. Sales by Outlet Size
- Grouped sales data based on Outlet Size using Pandas `groupby()`.
- Calculated the total sales for each outlet size.
- Created a pie chart using Matplotlib.
- Used percentage labels to visualize the contribution of each outlet size to total sales.

### 2. Sales by Outlet Location Type
- Grouped sales data based on Outlet Location Type.
- Calculated total sales for each location type.
- Sorted sales in descending order.
- Created a horizontal bar chart using Seaborn to compare sales across different outlet location types.

## Key Python Libraries
- **Pandas:** Data grouping, aggregation and sorting.
- **Matplotlib:** Creating pie charts and data visualizations.
- **Seaborn:** Creating attractive and informative bar charts.

## Project Objective
To explore sales distribution across outlet sizes and location types through data visualization and identify patterns in outlet sales performance.

## Conclusion
This analysis provides insights into how outlet size and location type contribute to total sales. Data visualization makes it easier to compare sales performance and understand business trends.
